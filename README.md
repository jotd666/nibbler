"# Nibbler" 
remake of Nibbler for Amiga (OCS)

Requires a joystick, or the keyboard

Credits:

- jotd: reverse-engineering, 68000 transcode, graphics conversion
  sound conversion for the Amiga.
- PascalDe73: icons
- Rock-Ola: original game

In original rom we find the following message:

WRITTEN BY JOE ULOWETZ FOR ROCK-OLA (C) 1982 ROCK-OLA MFG CORP


Instructions:

1/2/fire: start game
arrows/joystick: move


Cheat keys:

F1: skip level
F3: add 10000 points
