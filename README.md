"# Nibbler" 
remake of Nibblrt for Amiga

Requires a 2-button joystick, or the keyboard

Credits:

- jotd: reverse-engineering, 68000 transcode, graphics conversion
  sound conversion for the Amiga.
- no9 (soon): music
- PascalDe73: icons
- Rock-Ola: original game

In original rom we find the following message:

WRITTEN BY JOE ULOWETZ FOR ROCK-OLA (C) 1982 ROCK-OLA MFG CORP


Instructions:

5: insert coin
1/2: start game
arrows/joystick: move
red/ctrl: shoot
blue/alt: change weapon

Cheat keys:

F1: skip level
F3: add 10000 points
F4: toggle invincibility
